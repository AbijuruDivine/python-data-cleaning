# python-data-cleaning
Beginner-friendly data cleaning project using Python and Pandas to handle missing values, duplicates and data formatting in real-world datasets.
## Description
The project focuses on handling common data quality issues such as missing values,
duplicate records, and incorrect data formats.

## Tasks Performed
- Loading structured datasets (CSV files)
- Handling missing and null values
- Removing duplicate records
- Formatting date columns
- Exporting cleaned data

## Tools & Technologies
- Python
- Pandas

## Goal
To build strong foundational skills in data cleaning and data preparation,
which are essential for data engineering and analytics workflows.
